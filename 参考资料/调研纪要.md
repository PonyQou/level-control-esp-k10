# 项目一调研纪要（2026-11-11）

> 调研方式：多代理并行网络调研 + K10 官方原理图文本解析 + 官方 Arduino BSP 源码核对 + 社区验证过的 ESP-IDF 工程（ricklon/unihiker-k10）交叉比对。本文件是实验报告"AI 辅助开发过程"章节的素材。

## 1. K10 硬件事实（DFR0992，已三方交叉验证）

| 项 | 内容 |
|---|---|
| 主控 | ESP32-S3-WROOM-1-**N16R8**：16MB QIO flash + 8MB octal PSRAM，双核 240MHz |
| 屏幕 | **ILI9341**，240×320，4线 SPI，**无触摸控制器** |
| LCD 引脚 | SCLK=**GPIO12**，MOSI=**GPIO21**，CS=**GPIO14**，DC=**GPIO13**，无 MISO（只写，不能读回显存） |
| 背光 | **XL9535 P00**，高有效（需先点亮背光才能看到显示） |
| I2C 总线 | SDA=**GPIO47**，SCL=**GPIO48**（共享总线） |
| I2C 设备 | XL9535 IO扩展@**0x20**；AHT20 温湿度@**0x38**；LTR-303ALS 光感@0x29；SC7A20H 加速度@0x19；ES7243E 音频ADC@0x15 |
| 按键 A/B | **不在 ESP32 GPIO 上**：经 XL9535 读取，按下为低电平（10K 上拉）。⚠️ 引脚号更正（真机实测）：原理图网络名 "P5/KeyA"、"P11/KeyB" 的 P5/P11 是 micro:bit 边缘连接器引脚名，**XL9535 实际引脚为 A=P02、B=P14**（按下时观察输入寄存器 port0 bit2 / port1 bit4 跳变确认，2026-11-13） |
| BOOT/RST | BOOT=GPIO0（烧录时按住 BOOT 再点 RST 进入下载模式） |
| RGB LED | ×3 WS2812 @ GPIO46 |
| 方向约定 | 正面竖屏、USB-C 在上、A/B 键在屏下方；逻辑分辨率 240×320 |
| 其他 | TF 卡槽 + GT30L24A3W 中文字库芯片（SPI3）；摄像头 GC2145；无电池充电电路 |

**LVGL 屏参（ricklon 真机验证过）**：esp_lcd_ili9341 2.0.2 + LVGL 9.5.0 + esp_lvgl_port 2.8.0，40MHz SPI，颜色 BGR + RGB565 字节交换，2 个 240×40 局部缓冲，Y 镜像（X 不镜像）。⚠️ 镜像/字节序参数必须真机校准，留验收画面（四边 TOP/BOTTOM/LEFT/RIGHT + 纯色块）验证。

## 2. 固件技术选型（ESP-IDF **v6.1**）

- **v6.1 已发布**（stable，2026-08-27），与课程要求"乐鑫IDFv6.1"完全一致；v6.1.1 尚未发布。
- **安装方式已变**：旧的 esp-idf-tools-setup 安装器（2.4.1/5.5.6）**不支持 6.x**，官方唯一推荐 **EIM**（Espressif Installation Manager）v0.20.1。
- **esp-modbus v2.1.4**（托管组件）：IDF v5.0 起 freemodbus 移出 IDF、v6.0 删除了 v1 API 和旧示例。**v2 是句柄式 API**（`mbc_slave_create_tcp`），网上大量 v1 教程（`mbc_slave_init`）在 v6.1 编译不过。
- esp_lcd_ili9341 驱动内置；lvgl 9.5 + esp_lvgl_port 走组件注册表。
- XL9535、AHT20 自写 I2C 驱动（约 100 行级别，无现成 IDF 组件）。
- 官方 v2 示例已拷贝到 `参考资料/esp-modbus示例/mb_tcp_slave/`。

## 3. Modbus TCP 从站关键结论

| 项 | 结论 |
|---|---|
| 端口/站号 | `.tcp_opts.port=502`，`.tcp_opts.uid=1`；启用 `CONFIG_FMB_TCP_UID_ENABLED=y` 才严格校验站号 1 |
| WiFi | TCP 从站直接绑 WiFi STA netif 即可，**无需以太网**；创建从站不必等拿到 IP |
| 轮询 | v2 组件自建驱动任务（内部 select 循环），**用户不需要调 eMBPoll** |
| 事件 | `mbc_slave_get_param_info(handle, &info, 超时)` 非阻塞取读写事件，**不要用无超时的 check_event** |
| 共享数组 | 应用读写寄存器数组必须 `mbc_slave_lock/unlock` 临界区 |
| 断网 | 组件与 WiFi 事件零耦合：断网自动清理连接、监听 socket 常驻，重连后主站可直接重连；**不要销毁 netif**（否则会连带销毁 mb 依赖），只做 `esp_wifi_connect()` |
| 必须 | `esp_wifi_set_ps(WIFI_PS_NONE)` 关省电，否则延迟大、易掉线 |
| 校验 | 非法地址自动回异常 0x02；**参数值越界必须在应用层 WR 事件里校验** |
| 版本 | 用 ≥2.1.1（修复 TCP 从站漏帧 PR#131），即 2.1.4 |

**任务结构**（ESP32-S3 双核）：
- Modbus 驱动任务：组件自建，优先级 10
- 控制任务：20ms 定周期（`vTaskDelayUntil`）跑液位仿真，PID 按 PID周期执行；锁内刷新输入寄存器，优先级 ~8
- LVGL 任务：esp_lvgl_port 自建（可绑核心 1）
- WiFi 事件：系统事件循环处理重连

## 4. PC 上位机关键结论（Python 3.13）

- **pymodbus 3.16.2**（当前稳定版）。⚠️ 两个大坑：≥3.10 起参数名 `slave=` → **`device_id=`**；`pymodbus.payload` 模块**已删除**（旧教材的 BinaryPayloadDecoder 写法失效），改用 `client.convert_from_registers(regs, client.DATATYPE.FLOAT32, word_order="big")` / `convert_to_registers()`。
- float32 = 2 寄存器，统一 **ABCD 布局**（word_order="big"，`struct ">f"`）。
- **ModbusTcpClient 非线程安全** → 单工作线程独占 + 两个 queue 与 GUI 通信；GUI 用 `root.after(100)` 消费队列。
- 异常捕获顺序：`ConnectionException/ModbusIOException` → `ModbusException`；从站协议级错误不抛异常，用 `rr.isError()` 判断。
- GUI：**tkinter**（标准库，零依赖）；曲线：matplotlib 3.11.2 FuncAnimation；中文：`font.sans-serif=['SimHei','Microsoft YaHei']` + `axes.unicode_minus=False`。
- CSV：`utf-8-sig`（Excel 打开不乱码）+ `newline=""` + 每行 flush。

## 5. 本机环境相关坑（已实测）

1. **中文用户名路径**（C:\Users\陈智雄）：IDF 必须装到纯英文路径（如 `C:\esp`）。
2. **本机 GitHub 直连 TLS 失败**：装 IDF 必须走 `dl.espressif.cn` 镜像或 gitee，或设 `IDF_GITHUB_ASSETS=dl.espressif.cn/github_assets`。
3. pip 建议清华镜像。
4. Windows 建议开启长路径支持；杀软加白名单；EIM 不要以管理员运行。
