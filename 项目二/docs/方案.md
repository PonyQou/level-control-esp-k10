# 项目二：Modbus TCP → OPC UA 协议网关 —— 方案

## 技术选型：Python + asyncua（说明）

老师演示栈（open62541/C + nodeset_compiler）标注"仅供参考，不一定需要完全照做"。
本方案选 **Python + asyncua 2.1**，理由：

1. 项目二官方要求提交 zip"不要包含 .venv、build、__pycache__"——`.venv/__pycache__`
   是 Python 专属目录，说明 Python 实现是被认可的（甚至可能是默认）
2. 项目一已沉淀 Python 生态（pymodbus 3.16 + 寄存器表 + mock 从站），网关直接复用
3. asyncua 原生支持加载 OPC UA 官方 NodeSet XML（无需 nodeset_compiler 编译步骤），
   迭代速度快一个数量级
4. 网关是周期轮询 + 事件转发的 I/O 密集任务，Python 性能完全够用

DI 信息模型同样使用官方 OPC Foundation 的 DI companion NodeSet（nodesets/ 目录），
满足"基于 DI 规范的 DeviceType 建立 TankType"的验收要求。

## 架构

```
K10 (Modbus TCP 从站 :502)          PC 网关（本项目）             第三方 UA Client
┌─────────────────────┐   ┌──────────────────────────────┐   ┌──────────────┐
│ 输入寄存器 24 个    │◄──│ Modbus 轮询任务 (500ms)        │   │   UaExpert   │
│ 保持寄存器 26 个    │──►│  ├ 读全部寄存器               │◄──┤  browse/read │
│ (项目一寄存器表)     │   │  ├ 解码 ABCD float32          │   │  write/method│
└─────────────────────┘   │  ├ 更新 UA 变量（双向转换）     │   └──────────────┘
                          │  └ 处理 UA 写请求→FC16 写回    │
                          │ OPC UA 服务器 (asyncua)        │
                          │  ├ DI NodeSet (官方 XML)       │
                          │  ├ TankType (DeviceType 子类型)│
                          │  ├ Tank1 实例：变量+方法        │
                          │  └ 诊断变量（连接状态/错误）    │
                          └──────────────────────────────┘
```

## 信息模型（DI 规范）

```
DeviceType (DI ns, 官方 NodeSet 导入)
└── TankType (自定义 ObjectType, ns=3)
    ├─ SerialNumber / Manufacturer / Model    （DI 规范标准属性）
    ├─ Variable: Level, Setpoint(RW), Error, ValveIn, FlowIn,
    │            ValveOut(RW), FlowOut, Temperature, Kp/Ki/Kd(RW),
    │            PIDPeriod(RW), Area/Height/QmaxIn/QmaxOut/ExpN/Speed(RW)
    ├─ Method: SetSetpoint(value), SetValveOut(value),
    │          SaveParams(), ClearIntegral(), Start(), Stop()
    └─ 诊断: ModbusConnected, LastError, LastErrorTime, PollCount
        （Variable，网关运行状态）
```

## 双向转换

- Modbus 寄存器 uint16 对 ↔ UA 工程值（float）：与项目一相同的 ABCD 布局
- UA 写入越界 → 返回 Bad_OutOfRange（UA 状态码），不写寄存器

## 迭代里程碑（每步可独立验证）

| 里程碑 | 内容 | 验证 |
|---|---|---|
| G1 | UA 服务器骨架 + 加载 DI NodeSet | 客户端连接 + 浏览地址空间 |
| G2 | Modbus 轮询 + 变量映射（对 mock 从站） | 读变量 = mock 值 |
| G3 | TankType/DeviceType 子类型 + 方法 | 浏览类型层级 + 调用方法 |
| G4 | UA 写入 → Modbus 写回 + 越界拒绝 + 诊断变量 | UaExpert 写 Setpoint→K10 响应 |
| G5 | 真机联调 + 验收 | 全部验收项 |
