# UI 规格契约 V1 —— 实现与偏差清单

> 实现原则：契约是唯一需求源。颜色、字号、字重、控件结构、灯色语义 100% 按契约。
> 以下偏差全部由**模拟器实测数据**驱动（字体行高：雅黑 28b=33 / 24b=28 / 20=24 / 18=21px），
> 是契约数字与 240×320 物理屏幕冲突的必然结果，非自行发挥。

## 已实现的契约项（断言验证通过）

- 全部色值：#222222 / #333333 / #444444 / #FFFFFF / #D8D8D8 / #39E8F5 /
  #36D166 / #FFC145 / #FF4C4C；水箱白描边；液位填充 #39E8F5 alpha=0.8；上沿白线
- 字号字重：标题 28px 粗体（微软雅黑 Bold）；设定/实际数值 24px 粗体；
  IN/OUT 20px；IP/标签/状态/阀门 18px
- 控件结构：标题区 / IP&ID 行 / 主卡片（左水箱 100×144 + 右参数组 x=112）/
  状态卡（●主站 ●已到位 液温，圆点 10px）/ 阀门行
- 无数据规则：数据无效时数值显示 `--.--` 浅灰（已实现，随运行状态切换）
- 状态灯语义：ok 绿 / wait 琥珀 / err 红（主站：连=绿 断=红；已到位：到=绿 待=琥珀）

## 偏差清单（实测几何冲突）

| # | 契约要求 | 实际实现 | 实测依据 |
|---|---|---|---|
| 1 | 设定/实际 标签+数值同行 | 两行式（标签行+数值行） | "设定"+"250.0 mm" 同行需 ~170px，契约组宽 112px（24b 实测文本宽 114px） |
| 2 | 主卡片 h=160 | h=198（+38） | 四行总高 194px（21+28+21+28+24×4）> 契约内高 144px |
| 3 | 状态卡 y=240 h=44 | y=258 h=36 | 卡片加高后的顺延；内容（10px 圆点+21px 文字）36 足够 |
| 4 | 阀门行 y=290 h=26 | y=296 h=21 | 同上顺延；18px 文字行高 21 |
| 5 | 控件距边 ≥4px | 0~3px（9 处） | 契约盒子总高 316px + 内容实际高度的必然结果 |
| 6 | IP 行 "…:502[3空格]ID 1" | 1 空格 | 本机 IP 比契约示例长 2 位（15→13 字符），3 空格时行宽 241px 越界 1px |

## 若需消除偏差的备选方案（按优先级）

1. **缩小核心数值字号 24→22**：行 1/2 可同行（宽 ~150px 仍超组宽，需组宽放宽）
   ——不推荐，牺牲契约的重点字号
2. **水箱缩窄 100→88**：右侧组宽 112→124，仍不足以同行排布
3. **接受偏差**（当前选择）：全部字体/颜色/结构严格契约，布局以断言全绿为准
