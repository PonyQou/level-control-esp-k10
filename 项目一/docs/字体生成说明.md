# LVGL 中文字体生成说明

界面使用微软雅黑子集字体（`main/fonts/lv_font_cjk_16.c` / `lv_font_cjk_24.c`），
由 lv_font_conv 生成，仅包含界面需要的汉字 + ASCII，体积 200KB。

## 生成命令（已生成，仅记录流程；新增汉字时重跑）

```bash
# 1. 一次性准备
npm install lv_font_conv                       # 需要 Node.js
# 提取微软雅黑 TTF（lv_font_conv 不支持 TTC 集合格式）
python -c "from fontTools.ttLib import TTFont; TTFont(r'C:\Windows\Fonts\msyh.ttc', fontNumber=0).save(r'D:\esp\msyh.ttf')"

# 2. 生成（把新增汉字追加到 --symbols）
SYMS="行空板液位控制站设定实际值液温进出水阀主站已到位流量运行停止温度器设备当前状态水温℃±"
npx lv_font_conv --font D:/esp/msyh.ttf --format lvgl --size 24 --bpp 4 \
  -r 0x20-0x7F --symbols "$SYMS" \
  --output "main/fonts/lv_font_cjk_24.c" --no-compress --no-prefilter
# 同样命令 --size 16 生成 lv_font_cjk_16.c
```

## 使用

```c
#include "fonts/lv_font_cjk.h"
lv_obj_set_style_text_font(obj, &lv_font_cjk_24, 0);
```

## 采坑记录

- `msyh.ttc` 是字体集合（ttcf 签名），lv_font_conv 无法直接加载，
  需先用 fontTools 提取单个 TTF（matplotlib 依赖自带 fontTools）
- 若界面需要新汉字，只需加进 `--symbols` 重跑命令，不用重新生成全库
